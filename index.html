Anleitung

1. 6-Monats-Ziel einstellen

Unter „Einstellungen“ dein Gesamtziel für die sechs Monate eintragen. Die App verteilt dieses automatisch mit 40/30/15/15.

2. Monatswerte eintragen

Für jeden Bereich gibt es einen eigenen Reiter. Wähle den Monat und trage ausschließlich die Werte dieses Bereichs ein.

3. Dashboard

Das Dashboard berechnet automatisch Ziel, IST, Restvolumen und Fortschritt.

4. Analyse

Unter „Analysen“ kannst du einen einzelnen Monat oder die komplette 6-Monats-Entwicklung betrachten.

5. PDF

Analyse erstellen → „Als PDF speichern“ → im iPad-Druckdialog „Als PDF sichern“ auswählen.
